# Установка и настройка SQL Server 2014

Экземпляр (instance) SQL Server — отдельная работающая служба со своими базами, настройками и именами входа. SQL Server Management Studio, или SSMS, — клиент: он отправляет команды экземпляру. Установка одного SSMS не создаёт сервер.

Для будущей лаборатории нужен SQL Server 2014 Enterprise и инструмент управления, совместимый с ним. Старую версию изучайте в изолированной учебной среде. Состав компонентов выбирают по задаче: Database Engine нужен для SQL; Integration Services, Analysis Services и Reporting Services — для раздела BI. Они не появляются автоматически от создания базы.

**Порядок подготовки:** согласовать установку отдельно; проверить требования к ОС и дистрибутиву; выбрать экземпляр и служебные учётные записи; установить нужные компоненты; подключиться через SSMS; проверить версию и права. Не включайте все сетевые протоколы только ради локального занятия.

После подключения диагностический запрос выглядит так:

```sql
SELECT SERVERPROPERTY('ProductVersion') AS ProductVersion,
       SERVERPROPERTY('Edition') AS Edition;
SELECT name, compatibility_level
FROM sys.databases;
```

Для SQL Server 2014 основная версия — `12.x`. Совместимость `120` задаётся отдельно для базы: она влияет на поведение движка, но не превращает новый сервер в SQL Server 2014. Возможности поздних версий от этого не исчезают.

**Типичная ошибка:** путать имя компьютера, имя экземпляра и имя базы. Например, `LAB\SQL2014` — экземпляр, а `AdventureWorks2014` — база внутри него. На текущем компьютере установка не выполнялась.
