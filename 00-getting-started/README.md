# Введение и подготовка окружения

База данных — организованное хранилище сведений. В магазине велосипедов нужно помнить товары, покупателей и заказы. SQL Server хранит эти сведения, проверяет правила и позволяет нескольким приложениям работать одновременно. SQL — язык обращения к данным; T-SQL (Transact-SQL) — его диалект Microsoft с переменными, процедурами и обработкой ошибок.

Сначала научитесь читать таблицы и понимать результат запроса. Затем переходите к изменениям, программированию и транзакциям. Настройку скорости изучайте после правильности: быстро посчитанная неверная сумма не решает задачу бизнеса.

**Сквозной пример.** Покупатель оформляет два велосипеда. OLTP-база `AdventureWorks2014` хранит заказ и его позиции. Хранилище `AdventureWorksDW2014` позволяет сравнить продажи по месяцам и странам. В первом случае важна корректная запись конкретной покупки, во втором — согласованный подсчёт множества покупок.

Сейчас сервера нет. Читайте запросы построчно и вручную проверяйте маленькие наборы данных. Установка и восстановление ниже описаны для будущей лаборатории; никакие действия на компьютере не выполнялись. После создания лаборатории нужно проверить примеры на SQL Server 2014 Enterprise с совместимостью `120`.

**Результат раздела:** вы различаете сервер, клиент, базу и резервную копию и понимаете, как безопасно начать практику.
