# Маршрут обучения и способ работы с материалами

Учитесь в порядке оглавления. Разделы 00–02 учат читать данные; 03–05 — менять их без нарушения правил; 06–07 — объяснять производительность; 08–10 — обеспечивать работу сервера; 11–13 — строить аналитику; 14–15 — разбирать дополнительные возможности и задачи собеседований.

Для каждого урока используйте один цикл: прочитайте условие, предскажите результат, разберите пример, измените одно условие и объясните разницу. После появления сервера сравнивайте прогноз с результатом выполнения. Заметка «получилось» менее полезна, чем объяснение, почему получилось именно столько строк.

**Пример рассуждения.** В таблице товаров есть строки «велосипед, 1000», «шлем, 100», «насос, 50». Условие «цена больше 100» оставляет только велосипед. Сортировка по цене не меняет набор товаров, а только порядок. Уже здесь важно отделять фильтрацию от сортировки.

Каждую неделю возвращайтесь к старой задаче без подсказки. Для SQL проверяйте пустые наборы, одинаковые значения, `NULL` и отношения один-ко-многим. Для администрирования составляйте последовательность действий и критерии успешности.

**Самопроверка.** Можно ли считать тему освоенной, если удалось скопировать запрос? Нет: объясните назначение каждой части и приведите пример, при котором результат изменится. Готовность к собеседованию определяется этим навыком, а не количеством прочитанных страниц. Разделы администрирования и BI дают основу для дальнейшей практики, а не заменяют опыт эксплуатации.
