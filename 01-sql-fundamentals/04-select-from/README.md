# Базовый запрос SELECT

`SELECT` перечисляет столбцы результата, `FROM` задаёт источник. Это декларативное описание: «покажи нужные сведения», а не инструкция, как перебирать страницы базы. Завершайте команды точкой с запятой.

```sql
SELECT ProductID,
       Name AS ProductName,
       ListPrice,
       ListPrice * 1.10 AS PriceWithMarkup
FROM Production.Product;
```

Каждому товару соответствует строка результата. `AS ProductName` меняет заголовок результата, но не переименовывает столбец таблицы. Выражение умножает цену на 1,10 и ничего не записывает обратно в базу. Чтобы изменить данные, позже понадобится `UPDATE`.

Для начала можно прочитать запрос так: «из товаров возьми идентификатор, название, цену и расчётную цену с наценкой». Без `ORDER BY` порядок строк не гарантирован. Не считайте первое увиденное значение минимальным.

`SELECT *` означает все столбцы. Это удобно для краткого знакомства, но в прикладном запросе лучше перечислять нужные поля: структура может измениться, а лишние данные создают передачу и чтения. Даже `SELECT *` не означает «все таблицы»: источник по-прежнему задаётся отдельно.

**Упражнение.** Как получить только название и цену? Оставьте `Name, ListPrice` после `SELECT`. Количество строк останется тем же, а ширина результата уменьшится. Если два товара имеют одинаковые название и цену, без `DISTINCT` в результате останутся обе строки.
