# Выражения и встроенные функции

Выражение (expression) вычисляет значение из столбцов, констант и функций. Встроенная функция уже реализована движком. `LEN` измеряет длину строки без конечных пробелов, `UPPER` меняет регистр, `DATEADD` сдвигает дату, `DATEDIFF` считает пересечённые границы выбранной единицы времени.

```sql
SELECT ProductID,
       UPPER(Name) AS UpperName,
       CASE WHEN ListPrice = 0 THEN N'Цена не назначена'
            WHEN ListPrice < 1000 THEN N'До 1000'
            ELSE N'От 1000' END AS PriceGroup,
       ListPrice / NULLIF(StandardCost, 0) AS PriceCostRatio
FROM Production.Product;
```

`CASE` выбирает первое подходящее условие и возвращает одно значение. Это выражение, а не оператор выполнения разных запросов. `NULLIF(StandardCost, 0)` заменяет ноль на `NULL`, позволяя избежать деления на ноль: отношение для такой строки неизвестно.

`DATEDIFF(day, '20140101', '20140102')` даёт 1. Но разница на границе полуночи тоже может дать 1 даже между соседними секундами. Для возраста человека нужен дополнительный учёт того, был ли уже день рождения, а не только разница в годах.

**Ошибка:** смешивать число и текст в ветках `CASE`. SQL Server выводит общий тип по приоритетам и может попытаться преобразовать текст в число. Делайте ветви согласованными.

**Самопроверка.** Изменяет ли `UPPER(Name)` сохранённое имя товара? Нет: вычисление относится только к результату `SELECT`.
