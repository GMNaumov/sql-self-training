# Основы реляционных баз данных и SQL

Реляционная база представляет данные таблицами и связывает их ключами. Начните с отдельной строки и постепенно переходите к набору строк. SQL описывает, какие данные нужны; движок выбирает способ их получить.

**Пример.** В `Production.Product` каждая строка описывает товар. `ProductID` идентифицирует товар, `Name` называет его, `ListPrice` хранит цену. Запрос на товары дороже 1000 состоит из выбора столбцов, источника и условия. Он не требует писать цикл по всем товарам.

В разделе научитесь читать `SELECT`, подбирать типы данных, различать отсутствующее значение и ноль, фильтровать и сортировать результаты. Для чтения первых примеров достаточно знать, что `schema.table` — полное имя таблицы внутри базы. Предполагается контекст `AdventureWorks2014`, если не указано иное.

**Проверка понимания:** объясните, какие строки входят в результат, какие столбцы он содержит и гарантирован ли порядок. Это три отдельных вопроса. Количество строк без выполнения не угадывайте: оно зависит от содержимого демонстрационной базы.
