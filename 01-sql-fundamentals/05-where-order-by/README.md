# Фильтрация и сортировка

`WHERE` оставляет строки, для которых условие истинно. `ORDER BY` упорядочивает уже выбранный результат. `AND` требует выполнения обоих условий, `OR` — хотя бы одного. При смешивании используйте скобки, чтобы явно выразить намерение.

```sql
SELECT ProductID, Name, ListPrice
FROM Production.Product
WHERE ListPrice >= 1000
  AND (Color = N'Red' OR Color = N'Black')
ORDER BY ListPrice DESC, ProductID ASC;
```

Запрос выбирает дорогие красные или чёрные товары. `DESC` означает убывание цены, `ASC` — возрастание идентификатора. Второй ключ делает порядок определённым при одинаковой цене. Названия цветов в учебной базе английские, хотя объяснения русские.

Для интервала времени предпочитайте полуоткрытую границу:

```sql
SELECT SalesOrderID, OrderDate
FROM Sales.SalesOrderHeader
WHERE OrderDate >= '20140101'
  AND OrderDate <  '20140201';
```

Так попадает весь январь, включая время 31 января. `BETWEEN '20140101' AND '20140131'` включает обе границы, но верхняя дата при сравнении со временем означает начало последнего дня.

**Ошибка:** ожидать, что псевдоним из `SELECT` доступен в `WHERE` того же уровня. Логически фильтр обрабатывается раньше списка результата. В `ORDER BY` псевдоним обычно использовать можно.

**Самопроверка.** Чем отличается `>= 1000` от `> 1000`? Первая проверка включает точную цену 1000. Проверяйте граничные значения отдельно.
