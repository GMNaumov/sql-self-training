# Типы данных SQL Server

Тип данных (data type) определяет допустимые значения и операции. `int` хранит целые числа, `decimal(p,s)` — точные десятичные, `nvarchar(n)` — строки Unicode, `date` — дату, `datetime2` — дату со временем, `bit` — 0, 1 или `NULL`, если он разрешён.

Для цены обычно нужен точный тип: `decimal(12,2)` допускает всего 12 цифр, из них две после точки. `float` хранит приближённое число и неудобен для проверки равенства денежных сумм. Идентификатор заказа — число, но телефон обычно строка: у телефона бывают `+`, ведущие нули и добавочный номер.

```sql
SELECT CAST(10 AS decimal(12,2)) / 4 AS ExactResult,
       10 / 4 AS IntegerResult,
       N'Велосипед' AS ProductLabel,
       CONVERT(date, '20140131', 112) AS OrderDay;
```

Результаты деления — точное десятичное 2,5 с масштабом, определяемым правилами `decimal`, и целое `2`. Префикс `N` делает литерал Unicode. Стиль `112` явно задаёт формат даты `yyyymmdd` и исключает зависимость от языка сессии.

При сравнении разных типов движок может выполнить неявное преобразование (implicit conversion). Если строковый столбец содержит «нет», преобразование к числу завершится ошибкой. `TRY_CONVERT(int, N'нет')` возвращает `NULL` для такого преобразования и доступен в SQL Server 2014.

**Ошибка:** выбирать `nvarchar(max)` для любого поля. Ограниченная длина документирует правило и влияет на хранение и оценки памяти. Размер выбирают по реальным требованиям, а не по самому длинному текущему значению.
