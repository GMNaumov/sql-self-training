# Хранимые процедуры

Хранимая процедура (stored procedure) — именованный модуль команд в базе. Параметры отделяют значения от текста запроса и задают интерфейс операции. Процедура может вернуть строки, выходные параметры и целочисленный код возврата; это разные каналы.

Следующий модуль создаётся в отдельной учебной базе и читает AdventureWorks:

```sql
CREATE PROCEDURE dbo.GetCustomerOrders
    @CustomerID int,
    @FromDate date
AS
BEGIN
    SET NOCOUNT ON;
    SELECT SalesOrderID, OrderDate, SubTotal
    FROM AdventureWorks2014.Sales.SalesOrderHeader
    WHERE CustomerID = @CustomerID AND OrderDate >= @FromDate
    ORDER BY OrderDate, SalesOrderID;
END;
GO
EXEC dbo.GetCustomerOrders @CustomerID = 11000, @FromDate = '20140101';
```

`CREATE PROCEDURE` должен начинать свой пакет. `NOCOUNT ON` подавляет сообщения о количестве затронутых строк, но не скрывает результирующие наборы и не отключает `@@ROWCOUNT`. Если заказов нет, вернётся пустой набор.

Процедура не является автоматически одной транзакцией. Для нескольких связанных изменений нужно явно продумать начало, commit, rollback и обработку ошибок. Права на чтение другой базы также требуют отдельного решения: предоставление `EXECUTE` не всегда открывает межбазовый доступ.

**Ошибка:** возвращать бизнес-данные только через `RETURN`. Он рассчитан на целочисленный статус. Сумму продаж удобнее вернуть набором или параметром `OUTPUT` согласованного типа.

**Самопроверка.** Можно ли вызвать процедуру внутри `FROM` как таблицу? Обычным способом нет; для встраиваемого табличного выражения предназначена inline TVF.
