# Пользовательские функции

Пользовательская функция (user-defined function, UDF) возвращает значение либо таблицу и может встраиваться в запрос. Она не предназначена для изменения постоянных таблиц и управления транзакциями. В SQL Server 2014 особенно полезны встроенные табличные функции (inline table-valued functions, iTVF).

В отдельной учебной базе:

```sql
CREATE FUNCTION dbo.OrdersSince(@FromDate date)
RETURNS TABLE
AS
RETURN
(
    SELECT SalesOrderID, CustomerID, SubTotal
    FROM AdventureWorks2014.Sales.SalesOrderHeader
    WHERE OrderDate >= @FromDate
);
GO
SELECT CustomerID, SUM(SubTotal) AS Amount
FROM dbo.OrdersSince('20140101')
GROUP BY CustomerID;
```

Тело iTVF — один запрос. Оптимизатор рассматривает его вместе с внешним запросом, что помогает выбирать общий план. Функция с несколькими командами и возвращаемой табличной переменной — другой вид, multi-statement TVF; в 2014 оценки такого результата ограничены, полноценной статистики нет.

Скалярная функция возвращает одно значение. Если вызвать её для миллионов строк, построчная работа может стать дорогой. Автоматического встраивания scalar UDF из SQL Server 2019 в версии 2014 нет.

**Пример выбора:** расчёт простого отношения цены к себестоимости лучше начать с обычного выражения в `SELECT`; параметризованную повторно используемую выборку заказов можно оформить iTVF; запись заказа — процедура.

**Самопроверка.** Почему не стоит прятать любой расчёт в UDF ради красоты? Интерфейс влияет на оптимизацию и допустимые действия. Проверяйте план и объём вызовов.
