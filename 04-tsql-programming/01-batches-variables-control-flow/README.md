# Пакеты, переменные и управление потоком выполнения

Пакет (batch) — группа команд, отправленная серверу совместно. Локальная переменная живёт до конца пакета или модуля. `GO` в SSMS делит пакеты; после него объявленная ранее переменная недоступна.

```sql
DECLARE @MinPrice decimal(12,2) = 1000;
DECLARE @ProductCount int;
SELECT @ProductCount = COUNT(*)
FROM Production.Product
WHERE ListPrice >= @MinPrice;
IF @ProductCount > 0
BEGIN
    SELECT @ProductCount AS ProductCount;
END
ELSE
BEGIN
    SELECT N'Подходящих товаров нет' AS Message;
END;
```

`DECLARE` объявляет переменную, `SELECT` присваивает результат, `IF` выбирает ветвь. `BEGIN...END` объединяет несколько команд в блок, но не начинает транзакцию: для неё есть `BEGIN TRANSACTION`.

`WHILE` повторяет блок, пока условие истинно. Например, можно обрабатывать небольшие порции архивных записей, ограничивая размер транзакции. Однако простой расчёт цены для всех товаров обычно лучше выразить одним `UPDATE`, чем циклом.

**Ловушка:** `SELECT @x = Column FROM ...` с несколькими строками не определяет удобное правило выбора последней строки. Если строк нет, прежнее значение переменной сохраняется. Присваивание через скалярный подзапрос ведёт себя иначе: пустой результат даёт `NULL`, несколько строк — ошибку.

**Самопроверка.** Почему приложение получает ошибку на `GO`? Разделитель должен обработать клиент; обычный драйвер отправляет серверу T-SQL без `GO`.
