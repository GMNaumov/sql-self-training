# Программирование на T-SQL

T-SQL добавляет к запросам средства программирования: переменные, ветвления, повторения, модули и обработку ошибок. Они нужны, когда операция состоит из нескольких шагов, но не отменяют множественную природу SQL.

**Пример.** Оформление заказа проверяет параметры, создаёт заголовок и позиции, фиксирует изменения либо откатывает всё при ошибке. Хранимая процедура даёт этой операции имя и параметры. Транзакция определяет атомарность; само наличие процедуры ещё не делает набор команд атомарным.

В разделе сначала разберите область видимости переменных и временных результатов, затем процедуры и функции, триггеры, динамический SQL и ошибки. Для производительности старайтесь формулировать одно изменение набора вместо тысячи одинаковых изменений по строке.

**Контроль:** объясните, где живёт объект, сколько длится его жизнь, кто может его вызвать и что происходит при ошибке. Код создания постоянных модулей ниже предназначен только для будущей отдельной учебной базы. В SQL Server 2014 нет `CREATE OR ALTER`; для уже существующего модуля используйте отдельный `ALTER` после проверки его наличия.
