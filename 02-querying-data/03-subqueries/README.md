# Подзапросы

Подзапрос (subquery) — запрос внутри другого запроса. Скалярный подзапрос возвращает одно значение; табличный — набор. Коррелированный подзапрос использует столбец внешнего запроса.

```sql
SELECT p.ProductID, p.Name
FROM Production.Product AS p
WHERE NOT EXISTS
(
    SELECT 1
    FROM Sales.SalesOrderDetail AS d
    WHERE d.ProductID = p.ProductID
);
```

Это список товаров без продаж. `EXISTS` спрашивает только о наличии строки, поэтому `SELECT 1` не означает подсчёт. `NOT EXISTS` не размножает товары по количеству продаж и устойчив к `NULL` в несвязанных столбцах.

Пример скалярного подзапроса:

```sql
SELECT ProductID, Name, ListPrice
FROM Production.Product
WHERE ListPrice > (SELECT AVG(ListPrice) FROM Production.Product);
```

Средняя цена здесь рассчитана по всем товарам, включая нулевые цены. Если бизнес требует только товары в продаже с положительной ценой, фильтр среднего должен это отражать. Скалярный подзапрос без строк даёт `NULL`, а с несколькими строками вызывает ошибку.

**Ловушка:** `NOT IN (SELECT NullableColumn ...)` при наличии `NULL` может дать неожиданный пустой результат из-за трёхзначной логики. Явная проверка отсутствия через `NOT EXISTS` обычно проще.

**Самопроверка.** Коррелированный подзапрос всегда медленнее соединения? Нет: оптимизатор может получить одинаковые планы. Выбирайте выражение по смыслу и проверяйте фактические показатели.
