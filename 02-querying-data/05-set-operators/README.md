# Операции над множествами

Операции над наборами соединяют результаты по вертикали. `UNION ALL` сохраняет все строки, `UNION` устраняет повторы, `INTERSECT` оставляет общие строки, `EXCEPT` — строки слева, которых нет справа. Это отличается от `JOIN`, который сопоставляет столбцы и строки разных источников.

```sql
SELECT ProductID FROM Production.Product
EXCEPT
SELECT ProductID FROM Sales.SalesOrderDetail;
```

Получаем уникальные идентификаторы товаров без продаж. Оба запроса должны возвращать одинаковое число столбцов в одинаковом смысловом порядке с совместимыми типами. Имена столбцов результата берутся из первой выборки.

**Пример вручную.** Для наборов `[1,1,2]` и `[2,3]` `UNION ALL` даст пять строк, `UNION` — 1,2,3, `INTERSECT` — 2, `EXCEPT` слева направо — 1. Во время устранения повторов `NULL` рассматриваются как равные для сопоставления строк, в отличие от обычного сравнения `NULL = NULL`.

Общую сортировку пишите в конце всего выражения. Без неё порядок не гарантирован, в том числе порядок «сначала первая выборка, затем вторая». `INTERSECT` имеет более высокий приоритет, чем `UNION` и `EXCEPT`; скобки помогают выразить нужную последовательность.

**Ошибка:** выбирать `UNION` «на всякий случай» при объединении продаж из непересекающихся источников. Удаление повторов требует работы и может удалить две разные продажи с одинаковыми выбранными полями. Сначала определите ключ события.
