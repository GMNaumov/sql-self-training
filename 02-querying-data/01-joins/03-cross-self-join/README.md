# CROSS JOIN и самосоединения

`CROSS JOIN` создаёт декартово произведение: каждую строку слева сочетает с каждой справа. Для 3 размеров и 4 цветов получится 12 вариантов. Это полезно для календарных сеток и генерации комбинаций, но случайное произведение больших таблиц дорого.

```sql
SELECT c.Color, s.Size
FROM (VALUES (N'Red'), (N'Black')) AS c(Color)
CROSS JOIN (VALUES (N'S'), (N'M'), (N'L')) AS s(Size);
```

Здесь `VALUES` задаёт небольшой табличный источник прямо в запросе. Получится шесть сочетаний. Это возможные варианты, а не утверждение, что все такие товары существуют в AdventureWorks.

Самосоединение (self join) — обычное соединение одной таблицы с самой собой под разными псевдонимами:

```sql
SELECT a.ProductID AS FirstProduct, b.ProductID AS SecondProduct,
       a.Color
FROM Production.Product AS a
JOIN Production.Product AS b
  ON b.Color = a.Color AND a.ProductID < b.ProductID;
```

Запрос формирует пары разных товаров одного известного цвета. Условие `<` исключает пары товара с самим собой и зеркальные пары `(A,B)` и `(B,A)`. `NULL` цвета не совпадут через `=`.

**Ошибка:** считать self join специальным оператором SQL или автоматически связывать его с иерархией. Это способ дать таблице две роли. Иерархии — лишь один сценарий.

**Упражнение.** Сколько неупорядоченных пар образуют три товара одного цвета? Три: 1–2, 1–3, 2–3. Без `<` и с исключением только равных ключей было бы шесть.
