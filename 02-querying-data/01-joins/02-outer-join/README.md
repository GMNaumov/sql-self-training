# Внешние соединения

Внешнее соединение (outer join) сохраняет строки без пары, дополняя отсутствующую сторону значениями `NULL`. `LEFT JOIN` сохраняет левую сторону, `RIGHT JOIN` — правую, `FULL JOIN` — обе. Часто `LEFT JOIN` проще читать, чем переставлять направление в уме.

```sql
SELECT p.ProductID, p.Name, d.SalesOrderID
FROM Production.Product AS p
LEFT JOIN Sales.SalesOrderDetail AS d
  ON d.ProductID = p.ProductID
WHERE d.SalesOrderID IS NULL;
```

Запрос ищет товары без позиций продаж. Проверяется столбец правой стороны, который у реальной позиции не бывает `NULL`. Это позволяет отличить отсутствие пары от неизвестного значения обычного атрибута.

**Разница фильтров.** `LEFT JOIN ... ON ... AND d.OrderQty >= 2` сохраняет все товары и присоединяет только крупные позиции. Если перенести `d.OrderQty >= 2` в `WHERE`, строки без пары будут исключены: сравнение `NULL >= 2` неизвестно. Фильтр меняет смысл сохранения строк.

При подсчёте продаж через внешнее соединение используйте `COUNT(d.SalesOrderID)`, а не `COUNT(*)`: у товара без продаж внешнее соединение всё равно создаёт одну выходную строку.

**Самопроверка.** Вернёт ли `LEFT JOIN` ровно столько строк, сколько товаров? Не обязательно. Товар с несколькими продажами даст несколько строк; товар без продаж — одну дополненную строку.
