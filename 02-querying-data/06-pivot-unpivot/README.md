# PIVOT и UNPIVOT

`PIVOT` превращает значения признака в столбцы с агрегированием. `UNPIVOT` выполняет обратное изменение формы, но не восстанавливает подробности, потерянные при агрегировании. Такие формы удобны для отчёта «месяцы по столбцам».

```sql
SELECT CustomerID, [2013], [2014]
FROM
(
    SELECT CustomerID, YEAR(OrderDate) AS OrderYear, SubTotal
    FROM Sales.SalesOrderHeader
) AS src
PIVOT
(
    SUM(SubTotal) FOR OrderYear IN ([2013], [2014])
) AS p;
```

Выходная строка — покупатель, столбцы — суммы товаров в двух годах. Отсутствующее сочетание даёт `NULL`, который при необходимости отображают как ноль. Список столбцов статический. Не включайте в источник лишний `SalesOrderID`: он изменит неявный уровень группировки и раздробит результат.

Альтернатива — условная агрегация: `SUM(CASE WHEN YEAR(OrderDate)=2014 THEN SubTotal ELSE 0 END)`. Она часто яснее, когда нужны несколько разных показателей. Для фильтрации дат используйте диапазон, а `YEAR` оставьте выражением отображения, если важен индексный доступ.

`UNPIVOT` пропускает входные `NULL`. Поэтому перевод таблицы в длинную форму и обратно может потерять информацию об отсутствующих значениях.

**Самопроверка.** Как добавить новый год? Изменить фиксированный список столбцов или формировать проверенный динамический SQL. Не вставляйте непроверенные названия из пользовательского ввода.
