# Подготовка к собеседованиям

Собеседование проверяет не только синтаксис. Нужно уточнять условие, выбирать модель, объяснять правильность, проверять границы и обсуждать цену решения. Вопрос «последний заказ клиента» не определён до выбора даты, разрешения ничьих и поведения клиента без заказов.

**Порядок ответа:** переформулируйте задачу, назовите зерно результата и ключи, приведите маленький пример, напишите решение, проверьте `NULL`, повторы и пустой набор, затем обсудите индекс и конкурентный доступ. Не оптимизируйте неверную семантику.

Раздел содержит условия, решения и разборы прямо в Markdown. Сначала закройте решение и попытайтесь решить самостоятельно. После появления сервера выполните оба варианта на подготовленных данных и сравните результат. Сейчас ни один пример не объявляется проверенным запуском.

**Пример устного вопроса.** «Почему запрос иногда медленный?» Хороший ответ начинает с параметров, плана, чтений и ожиданий, а не с универсального rebuild. Ошибка 1205 требует повтора логической транзакции, а не добавления `NOLOCK` ко всем таблицам.

Завершите раздел пробным интервью: одна выборка, одна задача конкурентного изменения, один разбор плана и один сценарий восстановления. Объясняйте ограничения SQL Server 2014 и прямо называйте, чего ещё не проверили на стенде.
