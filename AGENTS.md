# Контекст проекта

## Назначение

Проект — русскоязычный самоучитель по Microsoft SQL Server для начинающего разработчика. Маршрут должен вести от нулевых знаний SQL до уверенного уровня собеседований в ведущие компании на позиции, связанные с разработкой программного обеспечения.

Обязательные направления:

- SQL и T-SQL: запросы, соединения, изменение данных, программирование, хранимые процедуры, функции и триггеры;
- проектирование баз данных и целостность данных;
- транзакции, блокировки и конкурентный доступ;
- производительность запросов, индексы, статистика и планы выполнения;
- In-Memory OLTP;
- администрирование SQL Server начального и среднего уровня, включая безопасность, резервное копирование, восстановление, мониторинг и высокую доступность;
- аналитические хранилища, аналитический SQL и компоненты BI;
- практика и разбор задач для собеседований.

## Технические ограничения

- Целевая версия: **Microsoft SQL Server 2014 Enterprise**.
- Все примеры и рекомендации должны учитывать возможности и ограничения именно SQL Server 2014. Не переносить без пояснений возможности более новых версий.
- Уровень совместимости демонстрационных баз при работе с SQL Server 2014: `120`, если в материале явно не рассматривается другой сценарий.
- Экземпляр SQL Server на компьютере не установлен. Выполнять запросы, восстанавливать базы и проверять команды на сервере сейчас невозможно.
- SQL-скрипты и инструкции можно создавать, но их нельзя считать проверенными выполнением. Не утверждать обратное; при необходимости явно отмечать, что проверка на целевом экземпляре ещё требуется.
- Не устанавливать SQL Server и не изменять системную конфигурацию без отдельного запроса пользователя.

## Демонстрационные базы

В корне проекта уже находятся резервные копии, предоставленные Microsoft:

- `AdventureWorks2014.bak` — основная OLTP-база для SQL, T-SQL, проектирования, производительности и администрирования;
- `AdventureWorksDW2014.bak` — аналитическая база для хранилищ данных, измерительного моделирования и аналитических запросов.

Не удалять, не перезаписывать и не перемещать эти файлы без явного запроса пользователя.

## Организация материалов

- Язык материалов — русский; технические термины при первом использовании желательно сопровождать английским эквивалентом.
- Каждая тема находится в отдельной папке, её материал — в файле `README.md` этой папки.
- Крупные темы делятся на вложенные папки.
- Имена папок — на английском языке, строчными буквами, с дефисами; числовые префиксы задают порядок обучения.
- Навигация реализуется относительными Markdown-ссылками в `README.md`: корневой файл ведёт к разделам, разделы — к темам.
- При добавлении, удалении или переименовании темы обновлять навигацию родительского раздела и, при необходимости, корневого `README.md`.
- Сейчас создаётся только структура. Тематические файлы должны оставаться заготовками без учебного содержания до отдельного запроса пользователя.
- Новые учебные материалы должны быть последовательными, практическими и опираться преимущественно на AdventureWorks2014 и AdventureWorksDW2014.
- Для будущих практических заданий предусматривать условия, эталонные решения, пояснения и типичные ошибки; не добавлять их в текущие заготовки.

## Проверка изменений

Поскольку сервер недоступен, проверять структуру каталогов, относительные ссылки и соответствие материалов SQL Server 2014 статически. После появления локального экземпляра дополнительно выполнять примеры на обеих демонстрационных базах там, где это применимо.

## Состояние структуры

- Маршрут обучения и заготовки тем созданы для всех 16 разделов, от `00-getting-started` до `15-interview-preparation`.
- Точка входа — корневой `README.md`. В крупных темах предусмотрены вложенные разделы со своими оглавлениями и ссылками на родителя.
- Следующий этап — наполнение тем только по отдельному запросу пользователя; наличие заготовки не означает готовность учебного материала.
