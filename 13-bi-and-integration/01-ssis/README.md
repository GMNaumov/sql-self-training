# SQL Server Integration Services

SQL Server Integration Services (SSIS) выполняет пакеты (packages) интеграции. Поток управления (Control Flow) определяет порядок задач, поток данных (Data Flow) — преобразование и передачу строк. Пакет содержит подключения, параметры, переменные и обработку событий.

**Пример проекта.** Пакет `LoadInternetSales` проверяет поступление файла, загружает staging, проверяет качество, выполняет SQL-загрузку фактов и сохраняет результат. Важные параметры — путь входа, подключение, идентификатор пакета загрузки. Настоящие секреты не должны находиться в репозитории.

SSIS не создаёт правильную модель автоматически. Нужно определить бизнес-ключи, порядок измерений и фактов, дубликаты, удаления и повторы после сбоя. Медленная построчная команда SQL в потоке может уступить загрузке staging и одной операции над набором.

В 2014 доступна project deployment model с каталогом `SSISDB`, наряду с более старой моделью package deployment. Выберите одну и явно опишите параметры и запуск. Наличие базы `SSISDB` требует отдельной настройки, в проекте её пока нет.

**Контроль:** извлечено = принято + отклонено; повтор не удваивает факт; частичная ошибка не публикует неверный набор; последнее успешное состояние и сообщения доступны оператору.
