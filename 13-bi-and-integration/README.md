# BI и интеграция данных

Business Intelligence (BI) объединяет загрузку, аналитическую модель и представление показателей пользователю. В экосистеме SQL Server SSIS переносит и преобразует данные, SSAS строит семантические модели, SSRS публикует параметризованные отчёты.

**Сквозной пример:** SSIS переносит новые продажи из OLTP в DW; SSAS публикует меру выручки с календарём и категориями; SSRS выдаёт руководителю отчёт по выбранному году. Каждый этап имеет собственную готовность: файл загружен, модель обработана, отчёт обновлён. Успех первого не доказывает успех остальных.

Для будущей практики нужны отдельно установленные компоненты и совместимые инструменты разработки для SQL Server 2014. Наличие `.bak` не устанавливает SSIS, SSAS или сервер отчётов. Пока разбирайте проекты, этапы и контрольные вычисления без заявления о выполнении.

Сначала изучите SSIS, затем сравните Multidimensional и Tabular, их языки MDX и DAX и перейдите к SSRS. Для SSAS Tabular 2014 ориентируйтесь на совместимость `1103`; это не уровень `120` базы Database Engine. Power BI и современные уровни модели не следует молча подменять историческим стеком курса.
