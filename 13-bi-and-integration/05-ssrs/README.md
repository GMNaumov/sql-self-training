# SQL Server Reporting Services

SQL Server Reporting Services (SSRS) создаёт серверные отчёты с параметрами, группировками, таблицами, графиками и экспортом. Определение отчёта хранится в RDL. Источник данных задаёт подключение, набор данных (dataset) — запрос и поля, макет — представление результата.

**Пример.** Отчёт «Интернет-продажи по месяцу» принимает год, выполняет агрегат по DW, показывает суммы и итог, позволяет выгрузить PDF или Excel. Выбор года должен передаваться параметром запроса, а не склеиваться в SQL-строку.

В SQL Server 2014 обычно используют Report Designer/Report Builder и Report Manager соответствующего поколения. Не описывайте современный web portal как гарантированно тот же интерфейс. Сервер отчётов и его базы требуют отдельной установки и настройки.

Разделяйте права просмотра отчёта и права подключения к данным. Источник со сохранёнными credentials может читать больше, чем конечный пользователь; поэтому фильтр параметра не становится надёжной границей безопасности сам по себе.

**Контроль:** сумма совпадает с SQL, пустой набор отображается понятно, параметры корректны, печатная страница не обрезается, экспорт проверен, подписка выполняется в нужном контексте. Успешный предпросмотр разработчика не доказывает работоспособность опубликованного отчёта.
