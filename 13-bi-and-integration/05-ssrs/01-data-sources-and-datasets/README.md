# Источники данных и наборы данных

Data source задаёт сервер, базу и способ входа; dataset — запрос и набор полей. Shared source можно использовать несколькими отчётами. Параметр отчёта связан с параметром dataset, но их нужно явно согласовать по имени, типу и значению.

Для DW запрос набора данных может выглядеть так:

```sql
SELECT d.MonthNumberOfYear,
       SUM(f.SalesAmount) AS Amount
FROM dbo.FactInternetSales AS f
JOIN dbo.DimDate AS d ON d.DateKey = f.OrderDateKey
WHERE d.CalendarYear = @Year
GROUP BY d.MonthNumberOfYear
ORDER BY d.MonthNumberOfYear;
```

В отчёте определите целочисленный `Year` и передайте его в `@Year`. В отдельном окне SQL для ручной проверки нужно объявить переменную либо подставить параметр безопасным способом. Выберите доступный в источнике год, а не автоматически текущий.

Старайтесь выполнять тяжёлую фильтрацию в SQL, а не загружать всю историю ради фильтра макета. Передавать много строк, которые отчёт затем скрывает, дорого и может расширить доступ к данным.

**Пример ошибки.** Отчёт работает у автора, но при публикации запрашивает пароль или выдаёт отказ. Проверьте credentials источника, права служебного контекста, делегирование при Windows authentication и доступ к DW.

**Самопроверка.** Одинаковы ли права «видеть ссылку отчёта» и «читать таблицы источника»? Нет, это разные уровни. Решение должно определять оба, включая запуск без интерактивного пользователя.
