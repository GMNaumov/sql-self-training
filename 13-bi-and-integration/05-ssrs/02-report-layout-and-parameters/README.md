# Макет отчёта, группировки и параметры

Tablix объединяет табличный и матричный макет. Группы задают уровни строк и столбцов, выражения — значения и итоги. Число и дата должны форматироваться как число и дата, а не заранее превращаться SQL-запросом в произвольный текст.

**Лабораторный макет.** Dataset содержит месяц и сумму. Добавьте таблицу из двух столбцов, сортируйте по номеру месяца, подпишите выбранный год, итог задайте `=Sum(Fields!Amount.Value)` в нужной области. Формат суммы — с двумя знаками. Название месяца выводите отдельно от ключа сортировки.

Область агрегата (scope) определяет, по каким строкам считается `Sum`. Итог группы, dataset и всей страницы могут иметь разный смысл. Если SQL уже вернул подробные строки и итоги, повторная сумма всех строк удвоит показатель.

Параметр должен иметь понятное имя, тип, допустимые значения и осмысленное значение по умолчанию. Для нескольких значений используйте поддерживаемое сопоставление, не собирайте непроверенный список в SQL-текст.

**Проверка печати:** ширина тела плюс поля не превышает ширину страницы; заголовки повторяются; длинные названия не перекрывают сумму; пустой результат содержит понятное сообщение. Предпросмотр HTML не гарантирует тот же вид PDF или Excel.

**Ошибка:** использовать `Hide` как защиту данных. Скрытые элементы и фильтры представления не заменяют серверные разрешения и контролируемую выборку.

**Самопроверка.** Почему алфавитный порядок месяцев неверен? Порядок отображения должен зависеть от календарного номера, а не от локализованной подписи.
