# Обработка, развёртывание и безопасность кубов

Развёртывание (deployment) переносит определение модели на SSAS. Обработка (processing) загружает данные и строит нужные структуры. Отчёт может обращаться к развёрнутой модели, но получать старые данные, если обработка не завершилась после ETL.

**Пример цепочки:** загрузить и проверить DW → обработать изменённые измерения → обработать соответствующие группы мер и структуры → сверить контрольную сумму → разрешить использование новой публикации. Тип processing выбирают по изменению; полный process может быть дорогим, а частичный требует понимания зависимостей.

Роль SSAS включает участников и разрешения модели. Dimension security ограничивает доступные элементы; cell security — доступ к ячейкам. Итоги и поведение ограничений нужно тестировать: скрытая детализация и скрытый вклад в общий итог не всегда одна задача.

**Лабораторная проверка.** Роль «регион A» видит только разрешённую территорию. Выполните запрос как тестовый участник и сравните с SQL-фильтром. Затем проверьте неизвестного участника, общий итог и доступ через инструмент отчётов.

Служебная учётная запись processing должна читать источник, а конечный читатель — иметь нужный доступ к модели. Не выдавайте всем администратора SSAS для устранения проблем входа. Резервируйте определения, конфигурацию и SSAS-базу согласно плану восстановления.

**Ошибка:** выполнять только deploy после изменения таблиц DW и ожидать обновившийся куб. Другой риск — успешный process на неполностью загруженном источнике. Публикация должна учитывать готовность всей цепочки.
