# SSAS Multidimensional

SSAS Multidimensional строит аналитический куб (cube) с измерениями, группами мер и иерархиями. Это семантический слой: он задаёт бизнес-значение показателей и удобные пути анализа, а не только ускоряет произвольный SQL.

**Пример.** Факт интернет-продаж становится группой мер Internet Sales, сумма `SalesAmount` — мерой выручки, календарь и продукт — измерениями. Пользователь выбирает 2014 год и категорию, не записывая каждый раз SQL-соединения.

Для будущего проекта подготовьте источник AdventureWorksDW2014, Data Source View, измерения с ключами и отношениями атрибутов, куб и measure groups, затем обработку и роли. Развёртывание определения не означает загрузку актуальных данных: нужен processing.

SSAS — отдельный экземпляр/служба в выбранном режиме. Multidimensional и Tabular не являются переключателем внутри одной SQL-базы; инструмент и сервер должны соответствовать модели. Данные `.bak` не содержат автоматически готовый проект куба.

**Контроль:** итог меры сверяется с SQL на том же срезе, иерархия даёт правильное включение элементов, неизвестные ключи не теряют факты, роли ограничивают нужный контекст. Язык запросов к многомерной модели — MDX; его наборы и контекст отличаются от строкового SQL.
