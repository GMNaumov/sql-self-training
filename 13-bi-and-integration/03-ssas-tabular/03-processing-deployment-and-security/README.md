# Обработка, развёртывание и безопасность табличных моделей

Развёртывание переносит структуру Tabular-модели, обработка загружает или обновляет данные. Импортируемая модель не читает каждое изменение DW мгновенно. Согласуйте частоту ETL, processing и ожидания пользователя.

**Пример расписания.** DW готов в 02:00; обработка стартует только после его успешной проверки; затем контрольная мера по дню сверяется с SQL; отчётам сообщается время актуальности. Если ETL завершился с ошибкой, не публикуйте модель на частичном наборе.

Роли ограничивают доступ к модели и строкам через поддерживаемые DAX-фильтры. Например, территориальная роль должна видеть разрешённые территории и корректные итоги. Проверяйте её как тестовый пользователь, включая поведение через отчётный инструмент, а не только предпросмотр администратора.

Для сервера SSAS 2014 нужен проект уровня 1103 и совместимые средства развёртывания. Не отправляйте современные JSON/TMSL-скрипты уровня 1200+ как команды для старой модели. Сохраните определения, параметры источника и процедуру восстановления SSAS-базы.

**Проверка ресурсов:** размер модели в памяти, запас на processing и одновременные запросы, длительность полного и частичного обновления. Маленький размер файлов DW не является точной оценкой потребления модели: влияют кардинальность и кодирование.

**Ошибка:** назначить пользователей администраторами, чтобы заработал просмотр. Административный контекст обходит ограничения роли и делает тест безопасности бессмысленным. Разделяйте обработку, администрирование и чтение.
