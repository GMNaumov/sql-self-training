# SSAS Tabular

SSAS Tabular представляет аналитику таблицами, связями и мерами DAX. Пользователю это может напоминать знакомую таблицу данных, но вычисления зависят от контекста фильтра и модели, а не только от формулы в отдельной строке.

**Пример.** Импортируйте `FactInternetSales`, `DimProduct` и `DimDate`. Создайте связи по `ProductKey` и `OrderDateKey`. Мера `Sales Amount := SUM(FactInternetSales[SalesAmount])` автоматически считает сумму в выбранном году и категории, если связи корректны.

Для SQL Server 2014 стандартная целевая совместимость Tabular — `1103`. Метаданные и инструменты этого уровня отличаются от современных Tabular `1200+`. Число `120` в настройке реляционной базы DW не устанавливает версию SSAS-модели. Источник: [уровни совместимости Tabular](https://learn.microsoft.com/en-us/analysis-services/tabular-models/compatibility-level-for-tabular-models-in-analysis-services).

Для начальной практики выбирайте понятный импортируемый пример. DirectQuery в старых уровнях имеет собственные существенные ограничения и не равен современным гибридным моделям Power BI. Изучите вычисляемые столбцы, меры, обработку и роли отдельно.

**Контроль:** одно и то же значение меры сверяется с SQL при тех же фильтрах; связи не теряют факты; потребление памяти и время обработки укладываются в план. Готового Tabular-проекта в `.bak` нет.
