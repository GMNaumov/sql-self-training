# Архитектура и службы SQL Server

Database Engine принимает подключения, проверяет права, компилирует и выполняет запросы. Buffer pool кеширует страницы. Log manager организует журнал транзакций. Фоновые процессы записывают изменённые страницы и выполняют обслуживание. Память кеша и постоянные файлы имеют разные роли.

Служба SQL Server Agent запускает задания по расписанию; остановка Agent не обязательно останавливает обычные запросы, но может остановить backup по расписанию. SQL Server Browser помогает обнаруживать некоторые именованные экземпляры. SSIS, SSAS и SSRS — отдельные компоненты со своими службами и конфигурацией.

```sql
SELECT @@SERVERNAME AS ServerName, @@VERSION AS VersionText;
SELECT sqlserver_start_time FROM sys.dm_os_sys_info;
```

Время старта полезно для интерпретации DMV: накопленные показатели могли сброситься недавно. Для административных представлений могут требоваться расширенные права; приложению их обычно не выдают.

**Пример сбоя.** Подключение к базе работает, но ночная загрузка не началась. Сначала проверьте Agent и историю задания, а не перестраивайте индексы. Если недоступен сам экземпляр, проверьте службу, сеть, имя и журнал запуска.

**Самопроверка.** Почему наличие `.mdf` не означает работающий SQL Server? Файл — хранилище; служба выполняет управление, согласование и доступ. Прямое редактирование файла внешним редактором не является способом изменения базы.
