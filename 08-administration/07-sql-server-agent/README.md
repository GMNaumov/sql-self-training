# SQL Server Agent: задания, расписания и оповещения

SQL Server Agent выполняет задания (jobs) с шагами, расписаниями, повторами и уведомлениями. Шаг T-SQL работает в указанной базе и контексте безопасности. Наличие SQL Server Engine не означает, что Agent запущен и задания настроены.

**Пример задания backup:** шаг 1 проверяет условия и создаёт копию в отдельной папке; шаг 2 выполняет согласованную проверку; при ошибке задание прекращается и сообщает оператору. Проверку восстановления обычно выделяют в отдельную полноценную процедуру стенда, а не называют любой `VERIFYONLY` полным restore-test.

В SSMS откройте SQL Server Agent → Jobs → New Job, задайте владельца, тип шага, базу и расписание. Для лаборатории сначала выполните вручную, проверьте историю успеха и ошибки, затем разрешите расписание. Здесь такой настройки не выполнялось.

Идемпотентность (idempotency) позволяет повторить шаг без повторного бизнес-эффекта. Например, загрузка должна отмечать завершённые пакеты, иначе автоматический retry удвоит продажи. Настройте ограничения повторов и защиту от перекрывающихся запусков смежных процессов.

**Ошибка:** проверять только последнюю зелёную строку истории. Изучайте длительность, время последнего успешного запуска, вывод шагов и полноту истории. Задание может завершиться технически успешно, но загрузить ноль строк из-за неверного пути.

Для внешних команд применяются credentials/proxy и минимальные права. Не запускайте все задания под широкими административными правами ради удобства.
