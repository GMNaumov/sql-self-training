# Администрирование SQL Server

Администрирование обеспечивает доступность, целостность и восстановимость данных. Для разработчика это помогает отличить ошибку запроса от нехватки места, блокировки, отсутствующего разрешения или остановленной службы.

**Пример рабочего дня:** проверить завершение резервного копирования, свободное место, ошибки, длительные задания и состояние баз. Зелёная отметка задания backup ещё не доказывает, что база восстанавливается за допустимое время. Для этого нужны учебные восстановления и проверка приложения.

Изучайте архитектуру и файлы перед настройками, модели восстановления — вместе с резервными копиями, мониторинг — через сравнение с нормальным состоянием. Не выбирайте значения памяти и параллелизма по одному примеру из интернета: они зависят от сервера и нагрузки.

Здесь приводятся диагностические запросы и сценарии будущей лаборатории. Команды изменения настроек, backup, restore и обслуживания не выполнялись. Все пути в примерах условны; серверная служба должна иметь к ним доступ. Исходные `.bak` проекта остаются источниками для чтения и не используются как выходные файлы резервного копирования.
