# Файлы баз данных и файловые группы

Данные хранятся в файлах данных (`.mdf`, обычно `.ndf` для дополнительных), журнал — в `.ldf`. Файловая группа (filegroup) объединяет файлы данных для размещения объектов. Журнал не помещается в обычную файловую группу данных.

```sql
SELECT name, type_desc, physical_name,
       size * 8.0 / 1024 AS SizeMB,
       growth, is_percent_growth
FROM sys.database_files;
SELECT name, type_desc FROM sys.filegroups;
```

Выполняйте в интересующей базе. Размер файла и объём занятых данными страниц различаются: внутри уже выделенного файла может быть свободное место. Свободное место диска — третья величина.

**Пример.** За месяц ожидается 20 ГБ загрузки. Предварительно выделенный объём уменьшает частоту autogrowth. Рост — страховка, а не основной план ёмкости. Фиксированное приращение проще прогнозировать, чем процент, который увеличивается вместе с файлом.

Несколько файлов данных не гарантируют ускорение, особенно на одном и том же физическом хранилище. Несколько файлов журнала не дают обычного параллельного ускорения записи: журнал используется последовательно. Чрезмерно частый рост журнала создаёт много virtual log files (VLF), усложняя некоторые операции восстановления.

**Ошибка:** удалять `.ldf`, чтобы освободить место. Это не очистка, а риск потери возможности восстановления. Сначала выясните `log_reuse_wait_desc`, модель восстановления и открытые транзакции. Уменьшение файла — отдельная обоснованная операция, не регулярная уборка.
