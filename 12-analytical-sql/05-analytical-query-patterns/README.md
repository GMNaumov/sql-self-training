# Типовые аналитические задачи

Аналитическую задачу удобно решать этапами: подготовить события, привести к нужному зерну, вычислить окна, применить итоговый фильтр и проверить инварианты. Типовые задачи — Top N на группу, доля категории, удержание клиентов и поиск периодов активности.

**Задача: доля продукта в интернет-продажах.**

```sql
;WITH ProductSales AS
(
    SELECT ProductKey, SUM(SalesAmount) AS Amount
    FROM dbo.FactInternetSales
    GROUP BY ProductKey
)
SELECT ProductKey, Amount,
       Amount / NULLIF(SUM(Amount) OVER (), 0) AS SalesShare
FROM ProductSales;
```

Контекст — DW. Сначала одна строка на продукт, затем общий знаменатель по этим строкам. Результат — доля от 0 до 1 при неотрицательных продажах; для процентов умножьте на 100. Типы должны сохранять дробную часть. На согласованном ненулевом наборе сумма долей близка к 1 с учётом округления.

Для Top N на группу используйте `ROW_NUMBER` или `DENSE_RANK` после согласования ничьих. Для удержания сначала определите когорту первого события и активность по периодам; не считайте несколько заказов одного клиента несколькими удержанными клиентами.

**Ошибки:** менять знаменатель фильтром раньше расчёта доли; смешивать историю и текущие признаки; сравнивать неполные периоды; усреднять отношения без весов.

**Самопроверка.** Если вывести только пять продуктов после вычисления доли, сумма показанных долей обязана быть 100%? Нет. Если отфильтровать до окна, знаменатель станет другим. Обе формы возможны, но отвечают на разные вопросы.
