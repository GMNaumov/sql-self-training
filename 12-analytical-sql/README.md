# Аналитический SQL

Аналитический SQL вычисляет показатели, сохраняя нужный уровень детализации. Оконная функция может добавить сумму покупателя к каждой его продаже; `GROUP BY` вместо этого сворачивает продажи в одну строку покупателя. Выбирайте форму по требуемой строке результата.

**Пример.** Нужно показать месячную выручку, нарастающий итог и разницу с прошлым месяцем. Сначала агрегируйте продажи до одной строки на месяц. Затем примените `SUM(...) OVER` и `LAG`. Если сразу считать по позициям заказов, «предыдущая строка» будет предыдущей позицией, а не предыдущим месяцем.

В разделе используем SQL Server 2014: он поддерживает оконные агрегаты с рамками, функции ранжирования, `LAG`, `LEAD` и `GROUPING SETS`. `DATETRUNC`, `GENERATE_SERIES` и `IGNORE NULLS` из поздних версий здесь не используются.

**Контроль:** определите зерно входа, разделы окна, порядок, рамку, равные значения и пропущенные периоды. Для времени используйте `DimDate`, чтобы различать отсутствие продаж и отсутствие календарной строки. Не утверждайте, что несколько предыдущих строк всегда равны нескольким предыдущим дням.
