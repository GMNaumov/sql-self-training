# Оконные функции

Оконная функция (window function) вычисляет значение по набору строк, связанному с текущей строкой, не сворачивая её. `OVER` задаёт раздел и порядок. Без `PARTITION BY` вся входная выборка образует один раздел.

```sql
USE AdventureWorks2014;
SELECT SalesOrderID, CustomerID, SubTotal,
       SUM(SubTotal) OVER (PARTITION BY CustomerID) AS CustomerAmount
FROM Sales.SalesOrderHeader;
```

Каждый заказ остаётся отдельной строкой, а итог покупателя повторяется рядом. Если у покупателя три заказа на 100, 200 и 300, рядом с каждым появится 600. Суммировать этот повторённый итог дальше как обычную выручку нельзя: получится 1800.

Есть оконные агрегаты (`SUM`, `COUNT`), ранжирование (`ROW_NUMBER`, `RANK`) и функции смещения/значений (`LAG`, `LAST_VALUE`). Не все функции принимают одинаковые элементы окна: например, ранжирование не использует рамку как оконная сумма.

Оконные вычисления логически происходят после фильтрации и группировки. Чтобы отфильтровать вычисленный номер, нужен внешний запрос или CTE. В SQL Server 2014 нет `QUALIFY`.

**Ошибка:** путать `ORDER BY` внутри `OVER` с сортировкой конечной выдачи. Первая задаёт порядок вычисления, вторая — представление результата. Если важен видимый порядок, укажите внешний `ORDER BY`.

**Самопроверка.** Сколько строк вернёт пример относительно таблицы заказов? Столько же, поскольку нет фильтра и группировки.
