# Функции ранжирования

`ROW_NUMBER` выдаёт последовательные номера, `RANK` сохраняет равенство и оставляет пропуски, `DENSE_RANK` сохраняет равенство без пропусков, `NTILE(n)` делит упорядоченные строки на примерно равные по численности группы.

Для цен 100, 100, 80 при убывании: row number — 1,2,3; rank — 1,1,3; dense rank — 1,1,2. Это разные ответы на вопрос «второе место».

```sql
;WITH Ranked AS
(
    SELECT ProductID, Name, ListPrice,
           DENSE_RANK() OVER (ORDER BY ListPrice DESC) AS PriceRank
    FROM Production.Product
)
SELECT ProductID, Name, ListPrice
FROM Ranked
WHERE PriceRank <= 3
ORDER BY ListPrice DESC, ProductID;
```

Контекст — OLTP. Запрос возвращает все товары с тремя наибольшими различными ценами; строк может быть больше трёх. Добавление `ProductID` в окно `DENSE_RANK` сделает почти каждый ключ уникальным и разрушит смысл равенства цены. Для стабильного отображения он используется только во внешней сортировке.

Для «ровно три товара» используйте `ROW_NUMBER` с уникальным разрешением ничьих. Для «верхние 10%» сначала уточните: по числу товаров, по рангу или по доле выручки. `NTILE(10)` не делает каждый сегмент равным по сумме продаж и может разделить одинаковые цены.

**Самопроверка.** На интервью «второй по зарплате» — это вторая строка или второе различное значение? Нужно уточнить условие до выбора функции.
