# Добавление данных с INSERT

`INSERT` добавляет строки. Перечень столбцов явно связывает значения с их назначением; без него код зависит от порядка столбцов таблицы. Значения по умолчанию (defaults) применяются, когда столбец пропущен или указано `DEFAULT`, а не при явной передаче `NULL`.

```sql
CREATE TABLE #Cart
(
    ProductID int NOT NULL,
    Qty int NOT NULL DEFAULT (1)
);
INSERT INTO #Cart (ProductID, Qty) VALUES (707, 2), (708, 1);
INSERT INTO #Cart (ProductID) VALUES (709);
SELECT ProductID, Qty FROM #Cart ORDER BY ProductID;
```

Третья строка получит количество 1. `#Cart` существует в текущем подключении; повторное создание без удаления даст ошибку. Завершение подключения удаляет локальную временную таблицу.

`INSERT ... SELECT` копирует результат запроса:

```sql
INSERT INTO #Cart (ProductID, Qty)
SELECT ProductID, 1
FROM Production.Product
WHERE ProductID = 710;
```

Если товара 710 нет, не добавится ни одной строки. Если источник выдаёт повторы, они также попадут в целевую таблицу, если ограничения их не запрещают. В данном упрощённом примере нет внешнего ключа и проверки положительного количества: для реальной корзины они или соответствующая прикладная модель необходимы.

**Ошибка:** ожидать, что проверка «товар существует» в отдельном запросе надёжно заменяет внешний ключ. Между проверкой и вставкой другой сеанс может удалить товар. Правила целостности рассматриваются далее.
