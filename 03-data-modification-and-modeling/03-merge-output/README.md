# MERGE и OUTPUT

`MERGE` сопоставляет источник и цель, выбирая вставку, обновление или удаление. `OUTPUT` возвращает сведения об изменённых строках. Удобный синтаксис не снимает вопросов конкурентного доступа и уникальности источника; для простых операций отдельные команды часто легче проверить.

```sql
CREATE TABLE #Stock (ProductID int PRIMARY KEY, Qty int NOT NULL);
INSERT INTO #Stock VALUES (707, 5);
UPDATE #Stock
SET Qty = Qty - 2
OUTPUT deleted.ProductID, deleted.Qty AS OldQty,
       inserted.Qty AS NewQty
WHERE ProductID = 707 AND Qty >= 2;
```

`deleted` показывает состояние до обновления, `inserted` — после. Ожидаемая строка результата: 707, 5, 3. Условие остатка и изменение находятся в одной команде, что лучше отдельной предварительной проверки. Если строки нет, приложение должно обработать отсутствие или нехватку остатка.

**Пример MERGE:** синхронизация маленького справочника цен по уникальному `ProductID`. Сначала проверьте, что источник содержит не больше одной строки на товар. Несколько строк источника, пытающихся обновить одну цель, могут вызвать ошибку. `WHEN NOT MATCHED BY SOURCE THEN DELETE` опасен, если источник содержит только сегодняшние изменения: он не является полным снимком.

Завершение `MERGE` точкой с запятой обязательно. Не считайте его универсально безопасным upsert: гонку двух вставок должны предотвращать ключ и продуманная транзакционная стратегия. Для 2014 учитывайте установленный пакет исправлений.

**Ошибка:** считать строки `OUTPUT` доказательством commit. Команда может вернуть их до последующей ошибки или отката; результат используйте с учётом завершения всей транзакции.

## Миниатюрная синхронизация

Продолжение с `#Stock`, созданной выше, показывает синтаксис на двух уникальных строках источника:

```sql
MERGE INTO #Stock AS target
USING (VALUES (707, 10), (708, 4)) AS source(ProductID, Qty)
ON target.ProductID = source.ProductID
WHEN MATCHED THEN
    UPDATE SET Qty = source.Qty
WHEN NOT MATCHED BY TARGET THEN
    INSERT (ProductID, Qty) VALUES (source.ProductID, source.Qty)
OUTPUT $action AS ChangeType, inserted.ProductID, inserted.Qty;
```

Товар 707 обновится до 10, товар 708 вставится с количеством 4. Это замена остатка по полному снимку выбранных ключей, а не прибавление поставки. Порядок строк `OUTPUT` не гарантирован. В примере нет удаления отсутствующих строк и нет имитации конкурентного upsert: временная таблица доступна одному сеансу. При переносе в общую таблицу нужен отдельный анализ уникальности, транзакций и исправлений конкретной сборки SQL Server 2014.
