# Уровни изоляции

Уровень изоляции (isolation level) задаёт, какие изменения других транзакций может увидеть сеанс и какие конфликты нужно предотвращать. Грязное чтение — чтение неподтверждённых данных; неповторяемое — изменение уже прочитанной строки; фантом — изменение набора строк по условию.

| Уровень | Основная гарантия и цена |
|---|---|
| READ UNCOMMITTED | Допускает грязные и другие несогласованные чтения |
| READ COMMITTED | Исключает грязные чтения; повторный запрос может отличаться |
| REPEATABLE READ | Сохраняет прочитанные строки, но допускает фантомы |
| SERIALIZABLE | Защищает также диапазоны; может сильнее блокировать |
| SNAPSHOT | Согласованный снимок транзакции; возможен конфликт записи |

По умолчанию для обычной базы используется `READ COMMITTED`; при выключенном RCSI чтение опирается на блокировки. `READ_COMMITTED_SNAPSHOT` меняет реализацию этого уровня на версии с согласованностью отдельной команды, а не всей транзакции.

**Сценарий двух сеансов.** A меняет остаток, но не делает commit. B читает его. При обычном `READ COMMITTED` B может ждать; при `READ UNCOMMITTED` увидеть значение, которое A позже откатит; при RCSI прочитать предыдущую подтверждённую версию.

Настройка сессии: `SET TRANSACTION ISOLATION LEVEL SERIALIZABLE;`. Снимки предварительно разрешаются настройками базы; не меняйте их в рабочей базе ради упражнения.

**Ошибка:** использовать `NOLOCK` как безусловное ускорение отчёта. Он допускает грязные чтения, пропуски и повторное чтение строк и всё равно может ждать блокировку схемы. Для финансового итога это обычно неприемлемый договор.
