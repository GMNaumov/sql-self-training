# Оценочные и фактические планы выполнения

Оценочный план (estimated plan) компилируется без выполнения основного запроса и показывает ожидания оптимизатора. Фактический план (actual plan) получают при выполнении; он добавляет показатели реально прошедших строк и часть предупреждений.

```sql
SET STATISTICS IO ON;
SET STATISTICS TIME ON;
SELECT SalesOrderID, OrderDate, SubTotal
FROM Sales.SalesOrderHeader
WHERE CustomerID = 11000;
SET STATISTICS IO OFF;
SET STATISTICS TIME OFF;
```

В SSMS включите Include Actual Execution Plan перед выполнением в будущей лаборатории. Для оценочного используйте Display Estimated Execution Plan. Нужны соответствующие разрешения, включая `SHOWPLAN` для участвующих баз.

**Пример различия.** Оценочный план ожидает одну строку, фактический показывает 5000. Форма плана может остаться прежней, но становится видно, почему тысячи Lookup стали дорогими. Фактический план не означает, что оптимизатор заранее знал правильный ответ и выбрал идеальный вариант.

Получение actual для `UPDATE` действительно выполняет изменение. Не используйте его как безопасный предварительный просмотр. Даже оценочное построение может требовать блокировок схемы и ресурсов компиляции; «без выполнения» не равно «без любой нагрузки».

**Самопроверка.** Можно ли измерить фактическое время только по estimated plan? Нет. Нужен запуск и измерения в контролируемой среде с зафиксированными параметрами и состоянием данных.
