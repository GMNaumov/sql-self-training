# SARGability и эффективные предикаты

SARGability означает возможность использовать условие для эффективного поиска по индексу. Обычно полезно оставить индексированный столбец без функции и преобразовать границы или параметр.

```sql
-- Менее удобное условие для индекса по OrderDate:
SELECT SalesOrderID FROM Sales.SalesOrderHeader
WHERE YEAR(OrderDate) = 2014;

-- Тот же календарный год как диапазон:
SELECT SalesOrderID FROM Sales.SalesOrderHeader
WHERE OrderDate >= '20140101' AND OrderDate < '20150101';
```

Первое выражение вычисляет год, второе задаёт непрерывный диапазон исходных значений. Подходящий индекс получает возможность ограничить чтение. Не обещайте конкретный план без данных и измерения: оптимизатор может предпочесть scan.

Для строк `LIKE N'Road%'` может задавать поиск по началу, а `LIKE N'%Road%'` обычно требует просмотра. Чувствительность к регистру и акцентам зависит от сопоставления (collation). `ISNULL(Color,N'')=...` меняет форму предиката; сначала уточните, действительно ли пропуск должен быть равен пустой строке.

Неявное преобразование типа индексированного столбца также может помешать поиску. Тип параметра подбирайте к столбцу. Для часто используемого детерминированного вычисления иногда подходит индексируемый вычисляемый столбец, но у него есть требования к выражению и настройкам.

**Упражнение.** Эквивалентно ли `ListPrice * 2 > 100` условию `ListPrice > 50`? Для обычных значений — да, но при переписывании выражений всегда учитывайте типы, округление, переполнение и `NULL`.
