# Высокая доступность и аварийное восстановление

Высокая доступность (high availability, HA) уменьшает простой при отказе; аварийное восстановление (disaster recovery, DR) возвращает сервис после серьёзной потери среды. Резервные копии, реплики и кластер решают разные части задачи.

**Пример.** Отказал узел — синхронная реплика может принять роль основной. Пользователь ошибочно удалил заказы — удаление обычно передастся и реплике; нужна историческая копия для возврата данных. Поэтому даже качественная HA не отменяет backup.

Сравнивайте решения по единице защиты, потерям, времени переключения, автоматизации и зависимостям приложения. AG защищает набор пользовательских баз, FCI — экземпляр, log shipping — восстановительную копию базы с задержкой, репликация — выбранные данные. Копия вне площадки добавляет DR-свойство только при работоспособном процессе восстановления.

В SQL Server 2014 рассматриваем Windows-реализацию и Enterprise. Basic AG, distributed AG и automatic seeding появились позже и не применяются. Для реальных лабораторий нужны несколько экземпляров и отдельная инфраструктура; сейчас приводятся сценарии и диагностика без установки или изменения системы.
