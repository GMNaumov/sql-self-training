# Дополнительные возможности SQL Server

Дополнительные возможности решают специальные задачи: XML — иерархические документы, пространственные типы — положение и расстояния, `hierarchyid` — пути дерева, Service Broker — транзакционные сообщения, Resource Governor — управление ресурсами, compression — сокращение хранения.

**Пример выбора.** Координаты магазинов требуют пространственной модели, обмен событиями между частями системы — очереди, а годовые отчёты по фактам — скорее аналитических индексов. Не используйте XML как замену всем таблицам только потому, что документ легко сериализовать.

Эти темы изучайте после основных запросов, проектирования, транзакций и производительности. Для каждой сначала сформулируйте задачу, затем границы инструмента и способ проверки. Вспомогательные функции не отменяют ключей, безопасности, backup и наблюдаемости.

В SQL Server 2014 здесь нет встроенного JSON-набора функций новых версий, автоматического управления произвольной нагрузкой и гарантии ускорения от сжатия. Примеры специальных объектов — будущие лабораторные сценарии, а не уже развёрнутые компоненты проекта.

**Результат:** уметь объяснить подходящий сценарий и ограничения, написать небольшой пример и назвать критерии проверки. Для глубокого промышленного использования каждого механизма потребуется отдельная практика.
